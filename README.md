# 🖥️ Screen Time

![Python](https://img.shields.io/badge/Python-3.12-blue)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![Version](https://img.shields.io/badge/version-1.0-green)

**Screen Time** — это desktop-приложение для Windows, которое отслеживает время, проведённое в различных программах.

Программа работает в фоновом режиме, собирает статистику использования приложений и показывает самые часто используемые программы.

---

## ✨ Возможности

✅ Отслеживание активного приложения в реальном времени  
✅ Подсчет времени использования каждой программы  
✅ Сохранение статистики между запусками  
✅ Работа в системном трее  
✅ Сворачивание приложения в фон  
✅ Темная и светлая тема  
✅ Автоматическое обновление статистики

## 🛠️ Использованные технологии

- Python
- CustomTkinter — графический интерфейс
- ctypes — работа с Windows API
- pystray — иконка в системном трее
- Pillow — обработка изображений
- JSON — хранение данных
- Threading — фоновые процессы

---

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-name/ScreenTime.git
```

### 2. Установка зависимостей

```bash
pip install customtkinter pystray pillow
```

### 3. Запуск

```bash
python app.py
```

---

## 📦 Запуск `.exe`

Готовая версия программы может работать без установленного Python.

Сборка выполнялась через:

```bash
pyinstaller --onefile --add-data "storage.py;." --add-data "func.py;." --add-data "logo.ico;." app.py
```

---

## ⚙️ Как работает программа

1. Программа получает активное окно Windows.
2. Определяет название процесса.
3. Каждую секунду увеличивает счетчик времени.
4. Сохраняет статистику в JSON.
5. Интерфейс показывает актуальную информацию.
